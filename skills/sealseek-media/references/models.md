## 参考方式与接口边界

- `--reference`：提供外观、内容或风格参考，不承诺作为精确首帧。
- `--first`：指定首帧；`--last` 指定尾帧，并要求同时提供首帧。CLI 将参考图模式与首尾帧模式分别处理，当前未验证两种模式混用。
- Seedance 2.5：支持参考图，当前目录不支持首帧、尾帧。
- HappyHorse t2v：纯文生视频；i2v 要求 `--first`；r2v 要求 `--reference`。
- Kling v3：支持首尾帧，不支持普通参考图；Kling v3 omni 支持参考图与首尾帧，分别选择对应模式。
- 视频每次生成一段；`--count` 为图片参数，独立像素尺寸未开放。

## 功能输入与接口边界

- `--video-reference`：目录声明支持视频参考的模型使用，可重复；上限读取模型参数。
- `--audio-reference`：Seedance 2 系列使用单段音频参考。Seedance 2.0 必须搭配 `--reference` 或 `--video-reference`，CLI 提交前检查；Seedance 2.5 可使用纯音频参考。
- `--audio true|false`：目录声明支持声音生成的模型使用。
- `--quality-mode std|pro`：Kling v3 / v3 omni 使用目录列出的质量模式。
- `image edit`：以 gpt-image-2、nano-banana-pro 或 nano-banana2 快速编辑已有图片；`image detect-text`：检测图片文字与位置；`image replace-text`：默认以 GPT Image 2 替换指定文字，亦支持 nano-banana-pro、nano-banana2、seedream-5-0、seedream-5-0-lite，可传检测返回的归一化坐标。
- 镜头控制和局部重绘蒙版尚未封装到 CLI；源接口已有专用局部重绘工具，这与通用生图模型的目录能力分别记录。精确像素尺寸控制实测未生效，CLI 提交前拒绝。风格迁移通过提示词与参考图表达。

这些输入来自官方无限画板 OpenAPI 与实时模型目录，真实生成范围由 `observed_runtime` 标注；参数校验成功不等于服务端生成成功。

## 校验、默认参数与结果核对

先执行 `models show ID --live --json`，再用 `generate --dry-run` 校验，通过后使用同一请求加 `--submit`。CLI 在准备时读取实时目录，读取失败就停止提交。`models estimate ID ... --json` 仅查询价格；价格查询成功不证明参数组合可生成。

`models show` 明确提供插件默认参数：比例 1:1、模型目录中的首个清晰度档位、图片 1 张；视频选择 5 秒（目录未列出时选首个时长）。这些参数会显式传给服务。

持续跟踪已保存的任务 ID。`task diagnose ID --json` 读取脱敏后的服务错误，不重新生成；`task inspect ID --json` 核对文件哈希、实际尺寸和视频时长。尺寸或时长可能取整，需要准确区分精确匹配和近似匹配。任务返回所选模型，不能独立证明实际服务模型身份。

## 真实验证范围

运行 `models show ID --live --json` 可读取该模型的 `observed_runtime`。每个案例标注接口、配置、完成状态和实际文件规格。历史 MCP 案例与当前无限画板案例按接口分别记录，不互相替代。未实测组合、参考数量上限及高级功能仍按目录声明或接口缺口标注。

## 高级参数与实测边界

`--video-options JSON_FILE` 的按模型字段、枚举与组合约束见 [CLI contract](cli.md#advanced-video-parameters)。读取 `models show ID --live --json` 的 `input_rules` 可获得机器可读规则。高级参数按官方 OpenAPI 声明接入，未实测组合保持 `provider_acceptance_verified: false`。

2026-10-08 的无限画板实测：8 个图片模型均有成功案例；视频已成功覆盖 Seedance 2.0、2.0 Fast、2.0 Mini、2.5、Wan 3.0、MiniMax H3、Kling v3 与 Kling v3 omni。图片参考、多图输出、快速编辑、文字检测和替换、视频参考均已有成功案例。HappyHorse 三种模型在本轮未取得成功结果，三个任务均返回服务端任务超时。

已有部分视频参考/首尾帧组合返回“响应格式无效”。CLI 保留模型、参数、远端任务 ID 和脱敏错误；这属于实测失败，不能从目录或文生视频成功推断该组合可用。Agent 查询和诊断原任务，不自行改参数反复提交。精确比例和秒数以实际文件检查为准。

Kling 自定义分镜列表实测被下游适配器拒绝（缺少 index），CLI 在提交前拦截 `multiShotPrompts`。智能分镜通过 `multiShot: true` 表达，已完成 5 秒、720p、1:1、图片参考的真实生成。

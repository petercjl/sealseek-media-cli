## 参考方式与接口边界

- `--reference`：提供外观、内容或风格参考，不承诺作为精确首帧。
- `--first`：指定首帧；`--last` 指定尾帧，并要求同时提供首帧。CLI 将参考图模式与首尾帧模式分别处理，当前未验证两种模式混用。
- Seedance 2.5：支持参考图，当前目录不支持首帧、尾帧。
- HappyHorse t2v：纯文生视频；i2v 要求 `--first`；r2v 要求 `--reference`。
- Kling v3：支持首尾帧，不支持普通参考图；Kling v3 omni 支持参考图与首尾帧，分别选择对应模式。
- 视频每次生成一段；`--count` 和 `--size` 为图片参数。

## 校验、默认参数与结果核对

先执行 `models show ID --live --json`，再用 `generate --dry-run` 校验，通过后使用同一请求加 `--submit`。CLI 在准备时读取实时目录，读取失败就停止提交。`models estimate ID ... --json` 仅查询价格；价格查询成功不证明参数组合可生成。

`models show` 明确提供插件默认参数：比例 1:1、模型目录中的首个清晰度档位、图片 1 张；视频选择 5 秒（目录未列出时选首个时长）。这些参数会显式传给服务，设置图片像素尺寸时除外。

持续跟踪已保存的任务 ID。`task diagnose ID --json` 读取脱敏后的服务错误，不重新生成；`task inspect ID --json` 核对文件哈希、实际尺寸和视频时长。尺寸或时长可能取整，需要准确区分精确匹配和近似匹配。MCP 不证明最终服务模型身份。

## 真实验证范围（2026-10-08，Codex / macOS）

- 19 个模型的比例、清晰度与时长目录已整理；本地校验覆盖 1423 个允许的参数组合及非法参数、参考数量边界。它们是校验测试，不是 1423 次真实生成。
- 对 MCP 可接受的 15 个模型 ID 各提交一次基础生成：4 个生图及 8 个生视频完成，快马 t2v/i2v/r2v 连接中断，结果未确认；查询历史暂未找到相应产物，保留任务并不自动重试。
- 额外验证 2.0 Fast 的固定比例首帧、adaptive 首帧、adaptive 首尾帧，均成功；Flare 4K 与 Seedance 2.5 1080p 也成功。
- 2.5 的 3:4 / 4 秒 / 480p 参考图请求实际为 560×752、4.041667 秒；1080p 请求实际为 1248×1664、4.041667 秒。Flare 4K 实际为 2480×3312。清晰度档位不是固定边长承诺。
- 剩余 4 个生图模型在 MCP 枚举校验阶段被拒绝，未产生真实生成。

运行 `models show ID --live --json` 可读取该模型的 `observed_runtime`，包括已实测配置、实际文件规格和未确认结果。参考数量上限、未逐项实测的组合及未开放高级功能，依然按目录声明或接口缺口标注。
